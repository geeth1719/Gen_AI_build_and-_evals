Here is a breakdown of how DeepEval calculates each of these four RAG metrics under the hood using its LLM-as-a-Judge methodology.

1. Faithfulness (Hallucination Detection)
Goal: Measures whether the LLM's actual_output is strictly supported by the retrieval_context without inventing facts.

How it is calculated:
Claim Extraction: DeepEval prompts the judge model (e.g., GPT-4o) to break down the actual_output into atomic, verifiable statements/claims.

Context Verification: For each extracted claim, the judge model checks if it is explicitly supported or logically implied by any sentence in the retrieval_context.

Score Calculation:

Faithfulness Score= 
Total Number of Claims Extracted
Number of Truthful Claims Supported by Context

2. Answer Relevancy
Goal: Measures whether the LLM's actual_output directly answers the user's input query, regardless of whether the answer is factually correct.

How it is calculated:
Statements Extraction: The judge extracts key statements made in the actual_output.

Irrelevant Statement Identification: The judge checks which of these statements directly address the user's prompt versus which ones are off-topic or redundant filler.

Score Calculation:

Answer Relevancy= 
Total Statements in Actual Output
Number of Relevant Statements
​
 
(Note: DeepEval also optionally calculates relevancy via embedding cosine similarity between generated queries from the answer and the original user query).

3. Contextual Recall
Goal: Measures whether your retrieval system retrieved all the necessary information required to construct the ground-truth (expected_output).

How it is calculated:
Expected Claims Extraction: The judge breaks down the expected_output (ground truth) into individual statements.

Context Matching: It checks how many of these ground-truth statements are present somewhere in the retrieval_context.

Score Calculation:

Contextual Recall= 
Total Statements in Ground Truth
Ground Truth Statements Attributable to Retrieved Context
​
 
What it tells you: If this score is low, your vector search / retriever failed to fetch important chunks required to answer the question.
